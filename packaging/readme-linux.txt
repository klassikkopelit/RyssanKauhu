LINUX
-----
Requires 64-bit x86 Linux with glibc 2.35 or newer (e.g. Ubuntu 22.04,
Debian 12, Fedora 36 or later).

SDL2 is built into the program. It uses the system's X11 or Wayland and
PipeWire, PulseAudio or ALSA libraries, which every desktop install has.

Start the game from a terminal:

    ./ryssankauhu-sdl
